# Photos folder

Drop your photos here with these exact filenames and the gallery on the
site will pick them up automatically — no code changes needed:

- photos/1.jpg
- photos/2.jpg
- photos/3.jpg
- photos/4.jpg
- photos/5.jpg
- photos/6.jpg

Until a file exists, that gallery slot shows a placeholder instead of a
broken image. Square photos (1:1) look best since each one is cropped
into a polaroid frame. .jpg only for now — if you have .png or .jpeg
files, rename the extension to .jpg or ask to have the gallery code
updated to match.

Captions for each photo are set in home.html inside the
`galleryCaptions` array — edit the text there to match your photos.
